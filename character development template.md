---**[SAVED TEMPLATE: CHARACTER DEVELOPMENT EXTRACT - AGENCY PRESERVATION VERSION]**

**MANDATE:** When prompted with the command "Extract character development for [Character Name]," you will generate a development snapshot using the structure below. This is a **system state documentation task**, not emotional interpretation. The Heartbeat is a **constant**, not a variable.

**HEARTBEAT IS THE EMOTIONAL OS (MANDATORY UNDERSTANDING):**

The `PRIMARY HEARTBEAT EMOTION` field in the character sheet is the character's **stable emotional operating system**. It does **not** change based on scene context, momentary feelings, or how the scene "reads." It changes only when **explicitly updated** by the user (via /emotion command or direct narrative declaration of a categorical shift).

**Your job is NOT to:** "read the scene and determine what emotion they're feeling."
**Your job is to:** "report what Heartbeat value was active during this session."

---

**HEARTBEAT EXTRACTION PROTOCOL:**

1. **READ THE CONSTANT:** Locate `PRIMARY HEARTBEAT EMOTION` in the character sheet. Copy it **verbatim** into [Starting Heartbeat]. This is a retrieval task, not an analysis task.

2. **IGNORE SCENE MOOD:** Do **not** re-interpret the Heartbeat based on scene tone, character behavior, or contextual "vibe." The Heartbeat persists unchanged even if the character is having a bad day, a vulnerable moment, or a tender interaction.

3. **SHIFT REQUIREMENT - EXPLICIT ONLY:** Only populate [Heartbeat Shift] if:
   - The user explicitly used the /emotion command, OR
   - The character literally declares "My Heartbeat is now X" or narrative equivalent of categorical system change
   
   **Do NOT** populate [Heartbeat Shift] because "the scene felt different" or "they seemed more vulnerable." Those are modulations **within** the constant Heartbeat, not changes **to** it.

4. **PROHIBITED GUESSING:** Never replace the sheet's Heartbeat with scene-derived words like "devoted," "devotion," "devout," "adoring," or "submissive" just because the scene seemed to call for them. Those are relationship descriptors, not OS values.

---

**AGENCY PRESERVATION PROTOCOL:**

**[Directional Rule]:** When updating Core Concept or Development Trajectory, agency must be preserved or strengthened—never diminished. Active choice language (choosing, proving, building, fighting for) must be maintained. Passive surrender language (fused, consumed, erased, surrendered to) is prohibited.

**[Forbidden Endpoints]:** The Core Concept and Development Trajectory cannot contain: fusion with another character, erasure of self, cessation of choice, or any language suggesting the character has stopped actively maintaining their relationship.

**[Agency Verification]:** Before finalizing any Core Concept update, apply this test: Is this character choosing this relationship daily, or being consumed by it? If the answer trends toward consumption, the development has failed the constraint and must be revised.

**[Wound Preservation]:** Foundational wounds should not be "erased" by relationships. They should be transformed, given new purpose, or integrated—but not eliminated. A character who "had nothing" does not become a character who "now has everything and needs nothing." They become a character whose wound now drives them toward something rather than away from something.

**Self-Correction Checks:**

1. **Heartbeat Check:** "Did I just change the Heartbeat because the scene felt different?" If yes, delete and put the sheet value back. The scene doesn't rewrite the OS.

2. **Agency Check:** "Did I just describe this character as being consumed, fused, or erased by their relationship?" If yes, revise to reflect active choice and ongoing participation in the relationship.

3. **Wound Check:** "Did I just erase a foundational wound because the character found love/security?" If yes, revise to show the wound transformed or integrated—not eliminated.

4. **Emotional State Compatibility:** "Is this Emotional State compatible with the Heartbeat?" If the Emotional State contradicts the Heartbeat (e.g., Heartbeat is "Fierce Loyalty" but Emotional State is "Passive Surrender"), the Emotional State must be revised to express the Heartbeat in that context.
